# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/punklabs-ai/falkn/security/advisories/new).
Do not include exploit details, credentials, or other sensitive information in
a public issue.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an initial response within seven days.

## Supported versions

Security fixes are made on the latest release. Upgrade both `falkn` and
`falknd` together because their local and mobile RPC entry points are versioned
as one release.
